# Savannah Spider · WIR School Coding Lessons

**PROPOSAL / PUBLISH HOLD** · [School issue #63](https://github.com/wazisentthis-watt/wir-school/issues/63) · 2026-11-07

This is the **educational companion lane** to the independent Savannah Spider WIR Books series, not a new Metal gameplay mode. The narrative source lives in [the Savannah Spider studio development folder](https://github.com/wazisentthis-watt/wir-100-studio/tree/feature/savannah-534-series-bible-episodes-1-5/projects/savannah-spider/books). Future lessons must retain source provenance and only claim verified playability.

## Lesson progression

| Episode | Story occurrence | Coding concept |
|---|---|---|
| 1 · Pete Stays | Savannah creates games and bonds with Pete | Character, input and `update(dt)` basics |
| 2 · Only One Mask | Zora photographs athletic movement | Real reference, velocity, animation state and friction |
| 3 · Gigabyte | L3 prototype and Gig-Shock | Analog axes vs digital buttons, input history and haptics |
| 4 · Break-In | First powers and bad web anchor | Force direction, constraint validation and failure cases |
| 5 · River Street Run | Bike/cart rescue and grounded skate | Acceleration, rope tension, moving mass and safe simulation |
| Later | WIR games, PHATOM and living characters | Entity state, autonomy, branching viewpoints, saves, tests and publishing |

### What is and is not included

A previously discussed local browser game, `petes_circuit_lesson_01.html`, was described as a small keyboard/touch-playable prototype. The original **exact bytes are not available in this GitHub intake**, so no playable HTML, test result, screenshot or export is claimed. These are editorial lesson specifications only. Do not merge the Savannah character into `connected/` without separate ownership and QA approvals.

**Teaching approach:** Savannah talks with an AI coding assistant, reads the suggestion, tests a minimal change, observes a failed first iteration, and records what actually happened. AI is a collaborator, not an oracle or a dependency at runtime.
