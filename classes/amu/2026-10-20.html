1 · Game: One-Behavior Robot

REALITY A computer runs instructions one at a time, in order, exactly as written. It never guesses what you meant.

WIR MODEL In Code Sorcery a “spell” is a function. Code isn't magic. A function is a named set of steps.

Rule: your robot does exactly ONE behavior. Name it first.

🤖 robot · ⭐ goal · dark squares are walls. Robot starts facing →.

Tap blocks to add them. Tap a block in your program to remove it. repeat 3 repeats the block right after it.

“What was the one behavior, and which block made it happen?”
