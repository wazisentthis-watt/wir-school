# METAL 73-power descriptions: mapping to the Complete Power Arsenal (PROPOSAL / HOLD)

Maps each entry in `connected/assets/metal_power_registry_73.mjs` to the owner's "Metal's Complete Power Arsenal" doc.

- **exact**: the same name in the arsenal doc. Description taken from the doc.
- **close**: a name-based guess at the arsenal entry. Owner to confirm or reject.
- **none**: no matching entry. The description is from the earlier design notes, or the power is name only.

The arsenal doc uses its own groupings (8 systems, a 40-entry movebook). This table does not change the 73-power registry or the game.
