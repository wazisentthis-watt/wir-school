Bend stage checker (PROPOSAL / Simulated only)

Scores a kinetic-chain move (Gate -> Root -> Hips -> Torso -> Shoulders -> Hands -> calm Settle) from a time series of SIMULATED pose landmarks. Aligned to AMU spec v0.2 (sec. 12). Weights order .45 / smooth .25 / timing .20 / hold .10. Order by each link's peak-speed time; speeds in shoulder-widths; gaps relative to chain span so slow movers are not penalized. Never scores force. Jump = score 0. Variants: full, seated, handsOnly; lead left/right/auto. All thresholds untested guesses. Not for live camera. Run: node --test tests/
